// export/hosts/vps.ts: the VPS adapter (SKETCH). A Linux box with Caddy, reached by SSH. It has
// no deployments of its own, so this adapter IS the convention (the minimum that gives the same
// three guarantees as Vercel: immutable builds, a preview link per build, live = a pointer):
//
//   /srv/ogw/<game>/
//     releases/<buildId>/        site/ of one export, never written again once complete
//     releases/<buildId>/.done   written last by publish (an upload without it is unfinished)
//     live -> releases/<buildId> the symlink Caddy serves; promote swaps it atomically
//
//   https://<domain>/                    the live build           (Caddy root /srv/ogw/<game>/live)
//   https://preview.<domain>/<buildId>/  any published build      (Caddy root /srv/ogw/<game>/releases)
//
//   publish: rsync -a --link-dest=../<live id> site/ host:/srv/ogw/<game>/releases/<id>.part/
//            then ssh: mv releases/<id>.part releases/<id> && touch releases/<id>/.done
//            (--link-dest hard-links unchanged files: the content-hash upload, for free)
//   promote: ssh: ln -sfn releases/<id> live.tmp && mv -T live.tmp live      (atomic rename)
//   history: ssh: ls releases/*/.done sorted by mtime; readlink live
//
// The Caddyfile block comes from Hosts.caddy_site (Bend) and is written once per game by
// `bun run deploy vps --setup` (prints it; the person installs it: we never edit /etc remotely).
//
// Limits now:
// - Previews by path need the bundle's URLs to be relative (Bun's HTML bundle writes "./_/...")
//   [U: verify with the real dist/]; otherwise previews move to <id>.preview.<domain> with a
//   wildcard certificate (DNS challenge).
// - Old releases are never deleted automatically: `deploys vps --prune 20` later.
// - One box: no CDN in front. Add one (Cloudflare proxy) when players are far from it.
