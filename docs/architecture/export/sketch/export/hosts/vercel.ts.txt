// export/hosts/vercel.ts: the Vercel adapter (SKETCH). Vercel's Build Output API is the model
// for our contract, so this adapter is almost a copy:
//
//   out/host/vercel/<game>/.vercel/output/config.json   <- Hosts.vercel_config(manifest)  (Bend)
//   out/host/vercel/<game>/.vercel/output/static/**     <- out/web/<game>/site/**        (copy)
//   out/host/vercel/<game>/.vercel/project.json         <- {orgId, projectId} of Settings.vercel_project
//
// Then the Vercel CLI does the rest; it already is "content-hash upload, immutable deployment,
// preview link, promote, rollback":
//   publish: vercel deploy --prebuilt --cwd <dir> --meta ogwBuild=<id> [--token $VERCEL_TOKEN]   -> preview URL
//   promote: vercel promote <deployment-url>                                                     -> production
//   history: vercel list <project> --meta ogwBuild=... / vercel inspect (JSON)                   -> Deployment[]
//
// Never builds on Vercel's machines: their image has no `bend` and no ../bend clone (2.0.40).
// `--prebuilt` uploads what we built, so the bundle Vercel serves is the one our laws passed.
//
// Limits now:
// - Hobby is for non-commercial use; 100 GB transfer a month, 100 deploys a day, 100 MB per CLI
//   upload (Pro: 1 GB), 15,000 files (Hosts.limits).
// - New projects protect preview links behind a Vercel login by default (Deployment
//   Protection) [U: check the team's setting]: to share a preview with a player, turn
//   protection off for previews or use a share link.
// - VERCEL_TOKEN can deploy AND promote: the person/agent wall of Hosts.may_promote is ours,
//   not Vercel's (RATIONALE: open questions).
