// publish/client.ts: the one client of the publish protocol (SKETCH, new in v2). HANDS ONLY: it
// reads keys, hashes files, sends requests and prints; every rule is a call into Bend
// (publish/protocol.bend, keys.bend, export/contract.bend). Its callers: publish/cli.ts (people,
// agents, CI) and tools/dev.ts's /_publish routes (the editor's Publish tab). There is no second
// path to a host: a new host is a new server speaking the protocol, never a new client.
//
//   push({ game, channel? })        export, then have -> blob -> release [-> point an Open channel]
//   promote({ to, id }, presence)   point a channel; Live needs a person (presence) and the typed confirmation
//   rollback({ to }, presence)      promote(Pr.previous(moves of `to`))
//   history({ game })               releases and every channel's moves, newest first
//   keys.mint / keys.revoke / keys.revokeAll / login
//
// Where the key comes from (butler's rule, read per grounding: mansion/authenticate.go):
//   OGW_PUBLISH_KEY in the environment, else ~/.ogw/publish.json (0600, written by `login` or by a
//   person pasting a key once). Never a flag (shell history), never the repo. With no key and no TTY
//   (CI, agents) it refuses instead of starting a login.
// Where the server is: OGW_PUBLISH_URL, else Pr's default service URL (TODO: Isabella's domain).
//
// Idempotent end to end: the build id is the content's; `have` skips what the store holds; a
// release that exists comes back with created:false; a move to the current pointer is NoChange.
// A crash anywhere leaves at most uploaded blobs, which the next push reuses.
//
// Limits now:
// - Blobs upload 4 at a time, each retried 3 times; no partial-blob resume.
// - The editor path runs this in the dev server process, so the browser never holds a key.
