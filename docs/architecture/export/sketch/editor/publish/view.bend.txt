# editor/publish/view.bend: the editor's Publish action, in Bend (SKETCH, new in v2).
#
# Where it appears: a fourth tab, "Publish", after Scene | Animation | Shaders in the toolbar of
# editor/workspace/view.bend (its `tabs`), with the same places as the other screens. The left
# column is the game's address, e.g. "ogw/character", and its channels with what each points at.
# The right column has the steps:
#   [Upload release]  -> runs what `bun run publish push` runs; shows progress, then the release's link
#   [Make live]       -> shows what changes (live id -> new id, both loads, credits, warnings),
#                        a text field "Type ogw/character:live 3c9e0a to confirm", the point secret field
#                        (VPS) or "Approve in your browser" (service), and the button, enabled only
#                        when the typed text equals Pr.confirm_text (the server checks it again)
#   [Roll back]       -> the same confirmation, for Pr.previous(moves)
#   History           -> releases newest first, the live one marked, each with its link
# No other control. Nothing here is invented: these are the CLI's verbs (Isabella's review: "a
# Publish action in the editor, written in Bend, doing what the CLI does").
#
# How it talks to the publish host: it does not. The page sends commands to the dev server
# (tools/dev.ts), on the same origin, and the dev server calls publish/client.ts, the same functions
# the CLI calls. So the browser never holds a key, there is one client, and the confirmation rules
# are the server's. The dev server refuses requests whose Origin is not its own page and that lack
# the per-session nonce it wrote into the page (another local page cannot publish).
#
# BARRIER: Bend-UI's Web.bend has no command for the network (its own "Limits now", read this
# session: Cmd is none | batch | delay | store_*). The tab needs one:
#   Web.request{method: String, url: String, body: String, on_reply: @+wire: String -> Ev, on_fail: Ev}
# This is a request to Bend-UI (Isabella's repository), not a workaround here: until it lands, the
# tab renders and its laws are checked, but its buttons say "needs Bend-UI request support".
#
# Limits now:
# - One game per editor (the open project): its address is the key's creator + PROJECT.folder(open()).
# - Progress is polled every 500 ms (Web.delay) from the dev server's job, not streamed.
